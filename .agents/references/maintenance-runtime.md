# Maintenance runtime

Use existing Git and Python 3 only; never install dependencies or modify PATH. Resolve the host-specific root per AGENTS.md. Discover Python once with `python3 -B scripts/maintenance_runtime.py` on Linux or existing `python`/`py -3` on Windows. If launchers fail, inspect trusted existing `%LOCALAPPDATA%/Programs/Python/Python*/python.exe` installations. Stop clearly if Python 3 cannot be determined. Freeze the absolute executable returned in JSON and reuse it throughout the workflow with `-B` or PYTHONDONTWRITEBYTECODE=1.

Run `<absolute-python> -B scripts/prepare_update.py --mode update` once for authorized update, or `--mode development` once for PR/development. Explicitly target the validated root on every execution. The helper validates exact fetch/push URLs, fetches explicit destination refspecs without changing remote.origin.fetch, rejects dirty/unfinished/unpublished/divergent state, and sets tracking. It never merges, resets, commits, pushes, or advances existing local branches. Update alone may add missing upstream. Development does not touch master/upstream. Partial ref preparation or network failure is not success.

Only positively identified Codex Cloud may set the project authorization marker `MINILOOT_MAINTENANCE_HOST=codex-cloud` and pass `--cloud-work`. This is our explicit authorization marker, not a built-in platform variable or independent proof. Confirm task/environment metadata first. Windows rejects the flag. Cloud work must be clean and an ancestor of freshly fetched origin/new-features. Existing project branches must have no unpublished/divergent history. Update also requires origin/master to be an ancestor of upstream/master. All history gates precede branch mutation. Create missing new-features/master only from matching origin refs; configure tracking explicitly; then switch from work. Never reset/delete/merge/publish work or derive project branches from it.

Reuse JSON ref SHAs and behind counts; separately fast-forward branches behind origin in the authorized workflow. Never repeatedly fetch/pull. Do not run preparation just for startup. Offline tests: `<absolute-python> -B -m unittest discover -s scripts/tests -v`. Validate syntax with ast.parse to avoid bytecode artifacts.
